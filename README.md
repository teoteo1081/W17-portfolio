# Thao Nguyen (TJ) — Portfolio

Single-file portfolio for a **Data-Driven Performance Marketer • AI Orchestration • Multilingual Growth Specialist**, built to be served from GitHub Pages.

## Features
- Dark / Light theme (dark by default), choice saved in `localStorage`
- Live language switcher: EN / VI / ES / ZH (no page reload, saved in `localStorage`)
- Interactive performance dashboard mockup (filters: All Regions, North, South, Direct Channels) using illustrative sample data
- Featured projects, learning lab and a sample contact form
- Responsive from 360px wide

## Tech
- One file: `index.html` (no build step)
- [Tailwind CSS](https://tailwindcss.com) via CDN (`darkMode: 'class'`)
- [Lucide](https://lucide.dev) icons via CDN
- Vanilla JavaScript: `toggleTheme()`, `switchLanguage(lang)`, `filterDashboard(region)`

## Run locally
Open `index.html` in a browser.

## Deploy
Repository Settings → Pages → Deploy from branch `main` / root.

## Notes
- Dashboard numbers are illustrative samples, not production data.
- Project links, LinkedIn and email are placeholders to replace before going live.
